## openACB — Resumen

**openACB** es una plataforma de analítica avanzada para la Liga ACB (baloncesto español), compuesta por dos partes:

### Backend (R)
- Procesa datos de play-by-play de acb.com
- Calcula estadísticas avanzadas (percentiles, ratings, similitud entre jugadores)
- Exporta datos a JSON para el frontend
- Gestiona 10 temporadas (2017-2026)

### Frontend (React)
- Aplicación web con Vite + Tailwind CSS + Recharts
- Secciones: Equipos, Jugadores, Herramientas, Alineaciones, Tiro
- Funcionalidades destacadas:
  - Perfiles de jugador con radar charts y arquetipos automáticos
  - Comparación entre jugadores y equipos
  - Análisis on/off y rankings de alineaciones
  - Cartas de tiro y líderes por zona
- Datos exportados en JSON con lazy loading por temporada

### Objetivo
Hacer accesible la analítica avanzada del baloncesto ACB de forma gratuita y en código abierto.
